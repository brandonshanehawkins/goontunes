# Brand Identity Specification: Ford Main Design System

This document defines the branding guidelines for the **Ford Main** client brand, used to create client-facing retail mockups and digital product designs.

---

## 1. Creative North Star: "Built for Motion"

The primary Ford brand identity is centered around modern retail environments, utility, and motion. 
- **Corporate Heritage & Retail**: Informational structure designed to drive vehicle configuration, search, and retail interactions.
- **Premium Fluidity**: Smooth transitions, highly professional typography, and a balance of rich photography and clear information.

---

## 2. Core Color Palette

| Token Name | Hex Code | Visual Role |
| :--- | :--- | :--- |
| **Ford Blue** | `#003399` | Primary action buttons, badges, links, and headers |
| **Deep Blue** | `#000f38` | Primary brand background or header text |
| **Ford Silver** | `#E6E6E6` | Secondary outlines, card dividers, and active surfaces |
| **Soft Canvas** | `#F5F5F5` | Background layout grids |
| **Pure White** | `#FFFFFF` | Core container surfaces |
| **Text Charcoal** | `#1A1A1A` | High contrast body copy and text elements |

---

## 3. Typography Rules

Uses the custom **FordMotion** (or **FordFont**) webfont-face (Light, Regular, Medium, Semibold, Bold).

- **Headlines & Headers**: FordMotion Bold or Medium, set with standard letter-spacing.
- **Subheads**: FordMotion Semibold.
- **Body & Captions**: FordMotion Regular or Light.

---

## 4. Shapes & Retail UI Elements

- **Border Radius**: Subtle modern rounding (e.g., `4px` or `8px` on buttons, inputs, and cards).
- **Elevations**: Subtle gradients and shadow cards (`var(--mcs-shadow-sm)`).
- **Deliverables**: Retail vehicle cards, feature lists, pricing blocks, configure buttons, and banner grids.
