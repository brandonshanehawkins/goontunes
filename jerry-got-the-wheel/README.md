# Jerry Got the Wheel - Music Player Site

This is a standalone static site music player generated by Static Music Player Builder.

## How to Host:
- **GitHub Pages**: Upload all files to a repository and enable GitHub Pages.
- **Netlify / Vercel**: Drag and drop this unzipped folder into Netlify Drop or Vercel.
- **Local Browser**: Open `index.html` directly in Chrome, Safari, Edge, or Firefox.
